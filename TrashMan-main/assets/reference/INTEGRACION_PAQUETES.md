Los archivos de `shaders/unity-reference/` y `RiverMap-Unity.cs.txt` son fuentes de Unity, no código que el navegador pueda ejecutar. El mapa Río Turbio del juego web se construye en `js/world/maps.js`: se añadió un cauce serpenteante, espuma discreta en las orillas y un puente de madera, conservando las texturas animadas de Three.js.

Los sonidos web se sirven como OGG desde `assets/sounds/`. Los WAV originales no se duplican para mantener el tamaño de descarga bajo.
